# Security Policy

Report suspected vulnerabilities privately to the repository maintainers rather than opening a
public issue. Include affected version, reproduction steps, impact, and any safe mitigation.

`agentic-init scan` is a deterministic helper, not a complete security audit. It can miss
threats and may report false positives. Do not paste secrets into issue reports, scanner output,
tickets, or generated configuration.

The latest published minor version receives fixes; earlier versions should upgrade when practical.
